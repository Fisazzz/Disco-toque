# Диско-электростанция

Одностраничный сайт-концепт вымышленной вечеринки в трансформаторном цехе 3030 года. Танцующие вырабатывают электричество через пьезопол, а накопленная за ночь энергия утром зажигает городские фонари.

**Сайт:** https://fisazzz.github.io/Disco-toque/
**Репозиторий:** https://github.com/Fisazzz/Disco-toque

## Что на сайте

1. **Обложка** — фото щита с знаком опасности, заголовок и кнопка «Вперёд».
2. **Пульт «Пуск»** — меню в виде щитка с двумя переключателями: «Концепт» и «Попасть».
3. **Концепт** — четыре карточки с идеей и индикатор накопленной энергии.
4. **Как попасть** — дни и время, расписание ночи, дресс-код, браслеты, правила цеха, место.
5. **Подвал** — контакты организатора и спонсор.

Навигация работает через якоря (`#start`, `#panel`, `#concept`, `#party`), плавная прокрутка включена в CSS.

## Технологии

Только HTML и CSS. JavaScript на сайте нет. Анимации (мерцание, заполнение индикатора) сделаны на CSS через `:target` и `@keyframes`.

## Структура

```
index.html            страница
stylesheets/
  reset.css           сброс стилей браузера
  fonts.css           шрифт и базовые настройки текста
  layout.css          сетка и расположение блоков, адаптив
  style.css           цвета, рамки, анимации
images/
  cover.JPG           фон обложки
  logo.png            логотип на шильдике
  favicon.svg/.png    значок вкладки
```

Порядок подключения стилей важен: reset → fonts → layout → style.

## Как запустить локально

Откройте `index.html` в браузере двойным щелчком. Или запустите локальный сервер:

```bash
python3 -m http.server 8000
```

и откройте http://localhost:8000.

## Публикация на GitHub Pages

Settings → Pages → Source: *Deploy from a branch* → ветка `main`, папка `/ (root)`. Через 1–2 минуты сайт появится по адресу выше.

**Важно:** GitHub Pages различает регистр букв в именах файлов (`cover.jpg` и `cover.JPG` — разные файлы), а macOS нет. Пишите имена файлов строчными латинскими буквами, без пробелов и русских символов, и ссылайтесь на них точно так же.

## Использование ИИ

Часть кода написана с помощью Claude (Anthropic) по моим описаниям. Идея, тексты концепта, дизайн и выбор решений — мои, код проверен и запущен мной. Места, где помогал ИИ, помечены в коде комментарием «ИИ: …».

| № | Что делал ИИ | Где |
|---|--------------|-----|
| 1 | Помог написать общий файл стилей | `stylesheets/style.css` |
| 2 | Разбил тексты концепта на карточки | секция «Концепт» в `index.html` |
| 3 | Написал структуру страницы «Как попасть» и часть текстов | секция «Как попасть» |
| 4 | Мерцание квадратов и значков, металлический шильдик с заклёпками | `style.css`, блок `.plate` |
| 5 | Пульт «Пуск» в графике, заполнение индикатора энергии | секция «Пуск», `style.css` |

> Проверьте таблицу: записи составлены по комментариям в коде, формулировки поправьте под себя.
